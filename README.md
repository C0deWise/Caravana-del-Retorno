# Caravana-del-Retorno
El proyecto busca crear una aplicación web para organizar y sistematizar procesos logísticos del evento Retorno en Florencia, Cauca. La herramienta estará enfocada en apoyar a las Colonias —grupos de florencianos residentes en distintas ciudades— en tareas como recopilar información de sus miembros, gestionar donaciones y difundir noticias.

## Ejecucion
